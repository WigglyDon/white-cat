# White Cat art direction

The approved visual authority is `concept_design_of_pixel_art_cat.png`:
“White Cat — Simplified Concept.”

White Cat is a minimal, quiet, watchful terminal glyph. The source is made only
from directly authored `24 x 26` fixed-string pixel maps. A single fixed `8x`
nearest-neighbor enlargement produces every `192 x 208` runtime frame.

The exact visible palette is:

- outline: `#2A3340`
- body: `#F4F2E8`
- shadow: `#CDD2D8`
- eye: `#86D7A8`
- transparent

Silhouette, posture, tail position, the single eye, and restrained timing carry
the character. Do not reconstruct the cat from geometry or normalize individual
frames.

The live audition contains five faithful readings of this authority. Only the
Authority candidate is currently packed into the runtime pet; the other four
remain idle-only review candidates until one is explicitly selected.
